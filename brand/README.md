# Seedee brand basics

Seedee helps creatives explore a personal creative agency. The identity pairs a growing seed with a studio foundation: room for creative ambition, supported by practical work. These are original review assets, not a trademark clearance opinion.

## Logo

![Seedee](wordmark-light.svg)

Use `wordmark-light.svg` and `mark-light.svg` on light surfaces; `wordmark-dark.svg` and `mark-dark.svg` on dark surfaces. The names describe the intended surface. All SVGs are transparent; the wordmarks contain outlined lettering, so no font download is required to display them. The mark is original geometric artwork. Keep clear space equal to one leaf width around the logo. Minimum displayed widths: wordmark 126 px, mark 28 px. Preserve proportions, colors, and leaf/stem relationships. For application accessibility, give a linked logo the name “Seedee home”; hide purely decorative marks from assistive technology.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Background | `#F8F6EF` | Primary off-white surface |
| Primary | `#355E3B` | Hunter green text, controls, strokes |
| Heading | `#1F3D2B` | Deep green headings and dark surfaces |
| Sage | `#DCE6D5` | Soft supporting panels |
| Ochre | `#D6A84B` | Small decorative highlights |

Use deep green or hunter green text on off-white; use off-white on either green. Both text combinations exceed WCAG AA for normal text. Ochre is decorative: do not use ochre text on off-white. Dark green may be used on sage. Parker owns final application tokens and UI integration; these assets supply the shared identity.

## Type and voice

Manrope is the single freely licensed family, bundled in `fonts/` with its SIL Open Font License. Use weight 750 for headings and 400 for body copy; web fallback: `Manrope, system-ui, sans-serif`. Static production instances use the family name “Seedee Manrope” to distinguish them from the upstream variable font. Keep body text comfortably spaced and use sentence case. Speak plainly: explore, shape, plan, prepare. Label sample outputs. Avoid revenue promises, unattended-company claims, and funding predictions.

## Flyer system

Bold invitation, symbolic seed-to-studio growth, and dark practical workflow form the three review variations in `marketing/flyers/`. Use each full landscape PNG without cropping away the disclosure. Print at 100% scale with the PDF TrimBox: 5 × 4 in; bleed extends 1/8 in on every edge. Preserve at least 1/4 in between trim and text. Sources, exact copy, reproduction steps and publication checks are recorded beside the exports.
