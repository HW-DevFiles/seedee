## How to reproduce

```sh
npm ci && npx playwright install chromium
npm run build -- --webpack            # or the default build, as CI does
E2E_PRODUCTION=1 npm run test:e2e     # temporary seeded DB, per-run sample password, HTTPS proxy
npx vitest run tests/qa-finance-parity.test.ts tests/qa-freshness.test.ts
```

Playwright never touches the developer database. It creates a temporary SQLite file, seeds the synthetic sample, and rotates the sample password for each run. The restart test migrates its own second database and starts its own production server on port 3400 (`E2E_RESTART_PORT`). CI now runs the browser suite with `E2E_PRODUCTION=1` against its production build and uploads `test-results/` on failure.

## Known limits of this QA pass

- **Provider failure and retry** cannot be triggered from the browser: the demo provider is deterministic and never fails on valid input, and there is no test hook. Recovery is covered by Nolan's injected-failure tests (`agency-engine.test.ts` "failed steps retry once…", "bounds provider runtime…"; `automation-bridge.test.ts` failure/retry projection) and by restart recovery (`agency-engine-db.test.ts`).
- **Clean install and container launch** are covered by CI's container job and `npm run platform:rehearse`, not by this suite. My restart test restarts the production Next server against the same SQLite file; it does not restart Docker.
- **Browsers**: Chromium only. No Firefox/WebKit or real mobile devices; 360 px is an emulated viewport.
- **Clock-dependent rules** (routine catch-up, DST, freshness ageing) are unit-tested with injected clocks; the browser runs on wall-clock time.
- **Development mode**: CI and I ran the suite against the production build. The specs also work under the dev server, except the production-only reset-refusal test, which skips there because a successful dev reset would delete the shared sample fixture.
- **Rate limits** are per-process SQLite buckets (export 10 per account per 15 minutes), as documented by Maximus; no distributed protection is claimed.
