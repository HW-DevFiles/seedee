# Web brand assets

These are serving copies of Ali's original outlined Seedee SVGs and bundled Manrope production instances from the shared brand package, https://github.com/HW-DevFiles/seedee/pull/4 (branch fm/seedee-brand-flyers).

The source assets and brand production records live under `brand/` in that package. SVG filenames describe their intended surface. Manrope is licensed under the SIL Open Font License; the complete license accompanies the fonts in `fonts/OFL-Manrope.txt`. The web build makes no font service requests.
